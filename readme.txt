Search appearance, sitemaps, social metadata, structured data and content analysis for WordPress.

== Description ==

SEOEarth is in early development and is not yet feature-complete. This readme will be completed before the first public release.

SEOEarth does not collect telemetry and does not contact external services.

== Installation ==

1. Upload the `seoearth` folder to `/wp-content/plugins/`, or install it from the Plugins screen.
2. Activate the plugin through the Plugins screen.
