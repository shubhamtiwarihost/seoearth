# Contributing

1. Read [DEVELOPMENT.md](DEVELOPMENT.md) for setup.
2. Branch from `main`; open a PR.
3. `composer ci` and `npm run lint:js` must pass locally; CI must be green.
4. New behavior needs tests. Security-relevant changes need a note in the PR describing input validation, escaping, nonces and capability checks.
5. Contributions must be your own original work, licensed GPL-2.0-or-later. Do not copy code, text or assets from other SEO plugins.
